# Feedback from testing, 2026-10-27

Working list from the user's test run. Status: [x] done, [ ] to do. Keep it current; it survives context resets.

## Quick fixes
- [x] Rate field label wrapped and sat lower than its neighbours → labels on one line, shorter Russian label.
- [x] Plan editor tabs Pay / Bills / Savings were not translated.
- [x] Settings had no obvious way back → "Done" button closes the window.
- [x] Today's icon buttons were unclear (airplane for sick leave, no visible tooltips) → named buttons: "Vacation, sick leave", "Balance on the card", "Edit plan".
- [x] Thousands separator: user dislikes commas, prefers dots → Settings → Look → Thousands: 1 000 000 / 1.000.000 / 1,000,000.
- [x] "Free to spend 0 ₽ / short by …" while the hero showed 4 653 a day from the card balance → clearer shortfall text and a "Lower savings…" button. (Revisit with the envelope model.)
- [x] Greeting "Good evening, Milana" on Today; theme choice (system / light / dark).
- [x] More saving suggestions: emergency fund, vacation, birthday gift for someone, New Year, car insurance, car service, taxes, health, education, renovation, gadgets. "Gifts for the whole year" is hard to estimate; prefer a gift for a person by a date.
- [x] More project templates: having a baby, university, wedding, renovation.
